# runtime capability validate|execute <path> — copy-paste cheatsheet
#
# A capability is a Markdown file with an embedded ```runtime workflow — see
# specs/capability-spec.md (seeded into the Runtime Home) for the full
# authoring contract. Storage is the author's problem: these commands work
# against any path, not just examples/capabilities/.

# Auth-free example — good for a first smoke test
runtime capability validate examples/capabilities/notes-roundtrip.md
runtime capability execute examples/capabilities/notes-roundtrip.md \
  --input path=./notes.txt --input message=hello

# Requires RUNTIME_GITHUB_TOKEN and `gh` installed + authenticated
runtime capability validate examples/capabilities/github-repositories.md
runtime capability execute examples/capabilities/github-repositories.md \
  --input organization=octocat

# validate reports every problem at once, not just the first:
#   - missing `version` / no workflow steps
#   - a workflow step naming a command that isn't a registered Runtime
#     Command (see internal/commands/commands.go)
#   - a `command.run` step naming a binary not in allowed_binaries
